## 尚待实网

`npm run probe:child` 默认输出 NOT_RUN，保存一次冻结 child 包而不执行世界。明确授权和请求上限后才可使用 --live。此探针隔离首个子判断，不调用生成器；legacy 为重建旧请求形状。首步选对仍不等于整任务可靠，需要随后完整任务测试。

没有证明新增语义上下文必定改变 Jev 的选择，也没有证明模型错误全部消失。此版修复受控恢复、重复计算、证据归属和可观察性；未新增自动认知诊断、深层递归或自我进化。
