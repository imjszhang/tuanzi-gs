# G/S Lab v0.4.3：以一场实验为中心的观测台

## 本版范围

这是信息架构、呈现和操作流程重组，不是新的决策算法版本。以 v0.4.2 发行包为基础，保留恢复机制、世界规则、父子 G/S、模型提示与任务图、预算、验收器、CLI、HTTP API 和事件协议。UI 与 npm 包号为 0.4.3；底层 Lab 状态协议、服务 banner、CLI 帮助与问题版本仍按其真实实现保留 0.4.2。这不是漏改运行时版本。

## 入口

启动 `npm start` 后打开 `http://127.0.0.1:4173/lab`。Node.js 22+；已经包含编译文件，试玩不需要 npm install。

默认进入实验列表。CLI 返回的 `/lab?run=...` 仍直达同一个服务端会话。网页读取、切换页签、查看证据不会推进引擎或请求模型。外部 Agent 仍通过 `bin/gs-lab.mjs` 和现有 API 操作。

`/` 与 `play.html` 保留本地体验，新增「完整任务体验 / 判断组合实验」切换，不再同时摆出两套运行上下文。隐藏主游戏时，其键盘快捷键不会误推进主世界。本地页不是服务端共享会话。

## 信息层级

### 实验列表

实验标题、类型、状态、配置来源和控制者优先；完整 runId 可检索，短 ID 辅助区分。创建、导入独立入口，不常驻新建参数表。

### 单个实验的四个页签

- **概览**：根目标、当前主持者、实际判断来源、地图、任务进展和资源、当前技能/阶段/即时任务、最近关键过程。
- **判断过程**：选择某次判断，查看问题、原始候选顺序、真实回答、概率或路由标记、输入事实，以及父子结果。完整过程与原始事件可追溯。
- **诊断**：可读原因、原始 reason、修复/请求/动作/时间预算、阻塞上下文与完整 JSON。未知错误不假造为已知原因。
- **配置**：本局实际参数和版本，只读。兼容字段 task=energy 不会被误写成主游戏目标。修改配置创建新实验，不改写正在运行的实验。

“已配置 Jev”不等于“已实际调用”；测试替身不标成真实模型。替身场景保留原始提供商路径计数，并明确它不是实网证据。界面摘要由注册状态和记录产生，不调用模型编写旁白，也不展示虚构思考。

## 操作流程

新建对话框先选择完整任务/判断组合，再选择程序化、Jev 或 Jev+LLM 预设。控制器、生成来源、预算等仍是可展开的独立配置维度，历史版本不再作为主要入口名称。

创建只分配就绪会话，不自动启动。取消草稿不影响当前世界。未配置模型时不能提交真实模式；每个新实验或实网分支必须单独授权。高级字段非法时展开所在分组以便修正。

非拥有者主要看到「接管并暂停」。操作员就绪时显示开始/单步，运行中显示暂停，取消需确认。`blocked` 是引擎终止状态，不显示“继续”；`paused` 才是可继续的操作员暂停。检查点、分支和干预置于更多操作中。权限与版本仍以服务端为准，前端按钮不是安全边界。

分支有独立对话框，显示检查点物理回合、世界版本和预算语义；显式选择经验继承及判断方式，不读取未提交的新建草稿。干预参数必须确认，在原接口规定的静止边界生效。

## 回放与断线

回放使用导出中的完整 `state` 快照。地图、状态、技能、判断和指标都对应同一个历史时刻，不使用历史地图搭配终局计数。只读期间不提供控制操作。缺失历史状态时仅展示有证据的最终快照，不补造过程。

实时连接从权威快照及事件序号续读，加载已有分页历史。断线显示陈旧快照提示并禁用写入；重连续读，不重启或补执行引擎。关闭网页不会停止实验。超过前端历史缓存界限时明确提示完整证据需导出。

## 桌面与手机

保留地图资产和绿色系。桌面概览采用地图与 G/S 当前过程并排，避免新建、编辑和预算工具各占一栏。手机把地图提前，四页签与模态流程代替桌面工具墙堆叠。具备键盘页签切换、对话框焦点返回、可见焦点与 reduced-motion 支持；不是正式无障碍合规认证。

## 实现边界

新增 `src/lab/presentation.ts` 为纯只读投影，`viewer-layout.ts` 管理观测布局，`viewer.ts` 保留同一 API 客户端控制。`src/ui/workspace-navigation.ts` 只组织本地界面。观测 bundle 不包含 GSEngine，也不创建第二个游戏世界。

复验中发现既有通用 API 允许 3,600,000ms 截止时间，但判断夹具自身只接受 120,000ms。新表单按任务范围设置输入上限，不悄悄截断用户值；CLI/API 仍按原协议，超出夹具范围的直接调用问题未在 UI 版本中修改。判断实验请设 deadlineMs<=120000。

## 升级

解压至新目录；保留自己的 `.env`、`.gs-lab/exports` 和本地修改。不要用整个新目录覆盖自定义的 thinking/reasoning 或超时改动。提供的源码差异补丁基于干净 v0.4.2，仅用于审阅合并，应用后需要重新构建。

仍仅供可信本机使用。没有新增持久运行恢复、跨设备权限、真实模型性能结论、递归深度或自动进化能力。历史原始 JSON 可导入只读查看。
