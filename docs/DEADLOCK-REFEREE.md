# 仅观察者可见的死局裁判

自主游戏实验增加独立环境裁判，策略标识为 `sound-static/v1`。它判断当前世界是否已经满足某个**足以证明根任务不可完成**的条件；判定成立时，宿主结束本局并记为任务失败。它不选择动作，不比较参考策略，不给 G/S 解释、提示或替代方案。

这是一组保守的充分条件，不是完备的死局求解器。`not-proven` 只表示这些条件未能证明死局，**不表示任务可完成**。复杂的能量、时间、动态守卫约束以及行为循环，仍可能超出本版裁判范围。

## 检查时机与结果

只应用于 `kind=game, controller=adaptive`。首次 `start` / `step` 在模型工作之前检查当前世界，每次物理动作之后再次检查。创建、读取、观看和导出不触发新的判定，也不调用模型。

检查前先执行已到期的计划干预。若还有未来干预，裁判返回 `not-proven / pending_interventions`：后续干预可能增加资源或改变通路，不能按封闭世界的前提提前判死局。原有终局、取消、供应商故障等结果保持原来的处理优先级。

已证实死局时，外层实验状态为 `failed`，原因是 `deadlock_proven:<rule>`；观察者结果的来源为 `environment-referee`。这与能量耗尽、G/S 协议失败、预算耗尽分别记录。裁判不会回滚已经执行的动作，也不会把失败记录改成模型自行识别了死局。

## 本版充分条件

| 判据 | 证明依据 |
| --- | --- |
| `insufficient_total_resources` | 已交付、背包和地图剩余浆果的总量仍不足目标。诱饵不能重新拾取，不计入可交付资源。即使忽略路程与能量，资源数量仍不够。 |
| `home_disconnected` | 忽略守卫与能量限制后，当前地形和障碍仍将团子与小窝隔断，且目标尚未完成。正常动作不能改变地形或拆除障碍。 |
| `stationary_resource_lock` | 背包为空、没有诱饵、守卫均已清醒并停在锚点，且团子所有安全可达位置都没有可拾取浆果。后续不能制造诱饵、让静止守卫离开或增加背包资源。 |

裁判只输出判据与支持它的事实，不输出通关路线、最优动作或替代策略。未满足充分条件时继续原来的自主过程；不能因一次未证实就扩宽动作权限或预算。

## 信息隔离与证据

- `state.referee` 保存最后一次裁判记录，包含规则版本、世界版本、结论、原因及证明事实；`observerOnly: true` 明确来源边界。
- 观察者事件使用外层 `type=deadlock_referee`，其中 `data.assessment` 为记录。它不是 `engine` 事件，不送回 G/S 的反馈历史。
- 导出中的 `evaluation.referee` 保存裁判记录。原始引擎轨迹、引擎结果及自主记忆保持原样，因此裁判判失败时，原引擎结果可能尚未终结；以带来源的外层实验结果区分两者。
- 网页展示死局失败及证明入口；未证实时明确提示“不代表局面可解”。裁判信息不进入 G/S 输入、动作候选、世界事实或继承记忆。

操作者不得把这些证明回填给当前或后续自主实验。裁判是世界外部的终止规则，不是团子的分析工具。它也不是针对主动读取宿主源码、文件或观察者 API 的安全沙箱。

## 实验比较

启用这项规则会改变实验的停止时机，应将 `sound-static/v1` 保留在新实验报告中。历史 live 报告保持原样；离线用历史状态检查新裁判，只能说明判据对那个状态的结果，不能把旧实验改写为按新规则运行，也不构成新的真实模型实验。

测试应覆盖命中充分条件、动态守卫和诱饵等反例、未来干预、模型调用前终止、动作后终止及信息隔离。测试控制器只用于机制验证，不是模型自行判断死局或通关的证据。此次加入裁判本身不要求重跑 live。
