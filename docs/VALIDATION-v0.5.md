# G/S Lab v0.5 验证记录

## 验证边界

本次没有调用真实 Jev 或 LLM，也没有读取用户的 `.env`。所有网络提供商测试为本机模拟HTTP或显式测试回调。`NOT_RUN` 不等于真实模型失败或成功。通关的微型夹具由测试控制器给定输出，只验证控制流，不是 G 独立解题的证据。

v0.5 以 v0.4.3 发行包为基线。主变化是独立的无参考解自主路径、G对S的有界上下文/选项重构和递归修订选择；环境物理保持原文件字节，历史参考算法继续独立测试。旧的带参考辅助实网入口被明确关闭，不声称其仍兼容。

前六项使用 `SCRIPTED_TEST_CONTROLLERS`。成功微型夹具起点已经交付4/5且身处小窝；不能误读成完整守卫果园通关。

默认本地 `LOCAL_ROTATION_NOT_A_SOLVER` 是动作轮换与上下文扩展夹具，不写入完整战术。在本次3次G上限下：meadow12动作，detour8动作，guarded18动作，remix18动作；四组都交付0、未成功。停止源于修订额度，真实外部请求全部为0。它们说明默认本地工具不是隐藏的求解器，不能据此预测真实模型表现。

`benchmark-v05.json` 与对应完整JSON是当前数据。此前运行时钟去重修正前的记录不作最终性能对照。绝对耗时依赖本机，未给模型成本、置信区间、未见场景或泛化结论。

## 浏览器限制与实际操作

曾实际尝试原生localhost导航，返回 `ERR_BLOCKED_BY_ADMINISTRATOR`。浏览器测试使用发行HTML字节 `set_content`，通过传输桥连接真实本地HTTP服务；桥用事件分页喂入流，原生SSE协议另由Node集成测试覆盖。不是原生浏览器HTTP导航、Safari/Firefox、公网或跨设备验证。

新界面实际检查：Agent CLI创建与写入同runId；网页观察同状态；创建默认自主路径与可见额度；参考路径强制离线；无凭据禁用实网；G处理中世界不变；修改前后证据；递归选择计量；接管/只读回放；移动端无横向溢出；持续弃权终止后不显示继续；配置和实际mock来源区分。页面error为空。

测试中修复了一处测试等待时序：会话快照先加载、历史事件后加载，断言必须等待对应runId真正绘制，不能把数据已获取当作界面已绘制。现在DOM绑定已绘制runId，未放松权限断言。

## 仍未证明或未实现
