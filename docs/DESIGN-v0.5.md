# G/S v0.5 — 有界自主调整与参考解隔离

## 1. 设计前提

S 不是完美控制器。它初始只看 self + nearby 的局部投影及部分公开规则，允许弃权和语义判断错误。G 获得允许的更广观测、公开规则、当前决策程序、S 的真实输入/选项/回答、近期实际执行反馈及自身历史记录。G 的职责是重新构造下层决策条件，而不仅是替换一个预写技能。

运行根目标仍是“保持存活并交付目标数量”。环境能力和目标不能被模型修改。G 的解释始终标记为未验证假设；只有真实世界后的根验收判定完成。

## 2. 为什么不继续在旧 SkillSession 上添加提示词

旧路径具有手写契约、战术位置绑定、参考控制器模拟准入。即使删除一个示例，其他辅助仍会完成部分求解。v0.5 因此提供新的 `controller=adaptive` 路径，使用公共原语和一般性的决策程序；旧控制器保留作离线对照，不允许实网选择/生成，也不允许旧记忆流入新路径。

这不是把 G/S 换成单一大模型直接行动。最终物理动作必须由 S 从当前候选中选择，G 不具有执行器权限。即使候选只剩一个，S 仍可以返回 none。

## 3. 运行序列

```
当前观察 + 当前决策程序
       ↓
实例化合法候选，形成局部 S 问题
       ↓
S 快速判断
  ├── 选出动作 → 复核版本/合法性 → 真实执行 → 实测反馈
  └── none / 观测到停滞或损伤 / 阶段结束或耗尽
       ↓
G：提出 1–3 个决策条件修订
       ↓
结构与权限检查（不做成功路径模拟）
       ↓
上层 S：选择哪个修订值得试行
       ├── 选中 → 应用上下文/候选/局部任务修订 → 返回下层 S
       └── none → 上一层 G 调整这次“选择修订”的问题 → 上一层 S
```

这里的分形是 `AdaptiveGS.loop()` 在动作与调整两个类型的 frame 上复用；不是仅在日志里画多层。深度0选择物理动作，深度1选择对其的修订，深度2可以选择如何改进深度1的选择。各层共用请求、时间和 G 配额；上层从不写游戏世界。

默认 maxDepth=2，可配置1..3。默认每层最多3次修订，范围1..6；默认整局G最多12次，范围1..32。单次 resolve 还受最多24个G生成的计算上限（与根剩余额度取小值）。有限上限不是“无限分形”的证明，层级结构也不是自主学习得到。

## 4. G 可以修改什么

`gs/decision-program/v1` 包含最多8个阶段。每阶段包含问题、未验证假设、可见观察组、公开规则ID、允许原语类别、可选目标坐标、可选候选ID子集、有限结束谓词与动作额度。

- 上下文：可以增加、删减或重组当前问题表达；选择 self/nearby/map/objects/history。
- 选项：从已实现原语中选择类别或当前具体候选；不创建新权限。
- 局部任务：G 自行选择坐标、子目标及阶段顺序；程序不会替它找“最佳投放点”。
- 内部元问题：G 可改变上层选择修订的题目、规则范围、可见观测和候选子集。

输出是受限结构数据，不执行生成的 JavaScript/TypeScript。合法 JSON 只是试行资格，不是成功认证。阶段 `until` 来自注册的 at / delta / value 谓词，仅决定局部结束，不能替代根验收。

当前仍不支持任意新工具、动态代码、通用逻辑证明、无限递归、自动归纳可迁移技能或训练模型权重。

## 5. 允许不完整，但不把失真当作不完整

S 的输入会显式列出 missingGroups。G 比 S 看得广，但都没有参考答案。当前能力存在与参数仍可见，不声称是严格的部分可观察决策理论环境。

事实表达区分：当前观测、公开原语定义、G 假设、真实后果。候选附带的目标距离是**到 G 自选目标的曼哈顿几何距离**，不是 BFS 路径长度或最优动作评分。没有 milestone 人工奖励、截断而未声明的 guardDistance、参考模拟的收益或推荐答案。

公开规则完整描述原语与守卫物理：这是环境说明，不是本关解法。状态里的 `scenario` 和 `lastFact` 开局攻略文案不传给 G/S；状态序列化使用字段白名单，附加参考答案字段不会透传。

## 6. 实际反馈与 G 修订

弃权时直接把当前 frame、完整选择结果及更广允许证据送给 G。执行后，根据实际资源变化、位置序列和守卫变化形成反馈；6步的重复状态/无进展检测是公开的开发者编写诊断启发式，不是最优解比较，也不保证准确识别一切错误。周期性 review 可以包含合理的长距离移动，G 需要自行判断是否应调整。

G 输入还包括最近3次动作级 S 输入与回答，避免仅有失败标签却看不到 S 如何判断。结构校验失败记录在本次修正历史中，不覆盖实际执行反馈。

在相同世界里重新组织证据是允许的；不要求必须先获得新的外部事实。框架去重针对有效决策问题/上下文/候选的规范化内容，不仅比较技能ID；只改程序标题或把相同阶段的已用动作计数清零，不视为新决策。自然语言的所有语义等价无法自动证明，根预算继续限制表面改写空转。

## 7. 参考解不能进入运行回路

自主路径明确不调用：`simulateSkill`、`bindPlacement`、`lureSite`、`searchProgram`、`parentRule`、`primitiveRule`、`selectPacket` 或旧技能库。没有解决本关的 few-shot 样例。G 服务端只追加结构契约。

环境模块仍包含世界物理所需的守卫移动路径计算；这属于环境如何变化，不是给 G/S 提供路线。自主选择器不调用该路径函数，也不向模型提供它的返回结果。

历史 hierarchy/program/rules 可独立运行、公开展示，用作参考，不与自主记忆共享。`evaluate-reference-v05.mjs` 只读取终局冻结导出、输出独立报告；没有返回运行时的回路。它不宣称全局最优，受控干预不一致时会警告不具有同条件可比性。

边界由专用模块、白名单、入口限制、跨模式记忆拒绝、静态调用审计和动态毒化字段测试共同检查。它不是操作系统隔离：拥有本机完整代码权限的恶意操作者仍可自行改程序；也无法证明预训练模型从未见过类似问题。

## 8. 记忆与证据归属

新记忆命名空间 `gs/self-memory/v05`，仅保留自身生成决策程序及其实际执行记录。字段区分 trial / local-completed / root-succeeded / failed / interrupted。中断、外部干预、被替换的试行不获得 root-succeeded 标签。off不保存；record保存但不送入G；use将有限近期自身记录送给G。

这不是离线最优轨迹库，也不承诺一次局部成功就学到了通用技能。只在明确的检查点分支中继承，不自动吞入旧版catalogue/book/reference结果。

## 9. 预算、取消和状态一致性

所有模型批请求与G请求由同一个服务账本计量，包含元层S。拆分问题仍按题数计数，一次合批不是免费计算。若深度/修订/请求/输入字节/动作/时间上限耗尽，明确停止；不能重启预算掩盖失败。

每次返回检查世界版本；弃权也要检查，不能把过期的none当作当前失败。G/S生成期间不写世界。已有在途取消不代表远端副作用已经撤销；本游戏环境写入在最终版本及合法性检查后同步发生。

一个CLI step至多执行一个物理动作，可能包含多轮内部调整。pause在这个量子结束后生效；cancel立即向全树传播。模型网络或响应契约错误不会静默换成规则求解。S的语义失败与供应商协议错误不是同一类问题。

## 10. 可观测性

保留v0.4.3四页签。概览显示G调整、S选择、递归层级和真实物理变化。诊断展示调整前后上下文/候选、当前程序及预算。元层选择有自己的实际题目与回答，不用旁白假装思考。

新导出包含G/S逻辑输入、输出和来源；服务端成功请求还记录无凭据的供应商请求正文及响应内容/答案。密钥仅在Authorization头，不能进入记录。实际调用账本与配置意图分开。

## 11. 评估含义

控制流夹具中G/S输出由测试回调规定，能证明恢复/递归/反馈路径工作，不能证明模型理解、通关或智能增长。默认动作轮换与上下文扩展同样不是解决果园的策略；其失败照实保留。

真实模型评估必须重新运行：这次移除了旧的战术辅助，候选和生成语言也改变，不能把过去9步参考模拟或85步程序成绩当作新模型路径的能力认证。最先应检验有限的真实S/G闭环，独立计算质量、实际成本、失败类型与恢复比例；禁止把参考答案作为“纠错反馈”。
