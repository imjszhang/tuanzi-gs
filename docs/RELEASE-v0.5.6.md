# G/S Lab v0.5.6 — 独立死局裁判

本版将已完成的死局判定纳入正式版本。自主游戏在任务已经不可完成时可以提前结束，证明只向观察者展示，不进入团子的决策过程。

## 新增行为

`kind=game, controller=adaptive` 自动使用宿主裁判 `sound-static/v1`。首次执行前及动作之后检查当前世界；创建和读取仍不调用模型。只有以下充分条件成立时才判死局：

| 判据 | 含义 |
| --- | --- |
| `insufficient_total_resources` | 已交付、背包与地图剩余浆果之和不足目标。 |
| `home_disconnected` | 即使忽略守卫和行动代价，固定地形仍隔断回家通路。 |
| `stationary_resource_lock` | 背包与诱饵均为空，守卫清醒且停在锚点，所有安全可达位置均无可拾取浆果。 |

判定成立后，外层实验为 `failed / deadlock_proven:<rule>`，来源为 `environment-referee`。它不回滚动作，不改写原始引擎结果，不记为模型自行判断失败。观察界面及导出保留证明。

`not-proven` 仅表示未能证明死局，不表示可解。仍有未来环境干预时暂缓静态证明；已到期干预先执行。复杂能量约束、动态守卫局面和行为循环不保证被识别。详细边界见[裁判设计](DEADLOCK-REFEREE.md)。

## 其他纳入本版的改动

- `maxGCalls` 的可配置上限从 32 提高到 256，默认仍为 12。实际运行仍受原请求、时间及其他预算约束。
- G 单次请求超时独立配置，默认 600 秒，支持 CLI、HTTP/MCP 和观察界面；S 超时保持不变，根预算及取消仍生效。
- 移除 SSE 响应累计 4 MiB 限制，保留单帧、最终文本、非流式响应和超时边界，支持长推理流。
- 纳入已合并的概率归一化边界修复：保留原容差，处理浮点舍入边界；无效完整答案保留验证元数据与已解析回答作为诊断证据，不按网络故障重试。这不证明此前某次无效回答一定由浮点误差造成。

本版没有实现空输出后的普通 G 重新生成恢复。原有格式纠错、同层调整、显式子问题及 Jev 有界重试继续有效。

## 升级与实验兼容性

Node.js 22+，没有新增运行时依赖。源码更新后执行 `npm run build`，再启动 `npm start`；已附编译文件的版本可直接启动。服务重启前应结束并导出活动实验，活动会话不支持跨进程恢复。

CLI / HTTP 命令及状态 schema 保持兼容，产品版本为 `0.5.6`；新增字段见 [API 增量](API-v0.5.6.md)。[MCP](MCP-v0.5.5.md) 与 [Jev 重试协议](RETRY-v0.5.5.md)继续适用。旧档案保持原版本、原结果。

新裁判改变停止时机，应在跨版本实验比较中记录 `sound-static/v1`。发布前已进行真实模型实验；最近一次在交付 3/5、执行 36 个动作后由外部裁判证明死局，不能视为模型完成任务。详见[验证记录](VALIDATION-v0.5.6.md)。
