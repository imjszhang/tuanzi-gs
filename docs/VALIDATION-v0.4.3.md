## 测试方式与限制

Node.js 22.16.0 / TypeScript 5.8.3 / 系统 Chromium。默认浏览器可执行路径 `/usr/bin/chromium`，可用 CHROMIUM_PATH 替换。

本环境阻止浏览器直接导航 HTTP/file URL。浏览器用 `set_content` 装载本次真正构建的 HTML/CSS/JS；共享观测台通过显式传输夹具请求真实本机服务，事件分页转换为浏览器流以验证消费逻辑。原有 Node 集成测试另行验证真实 HTTP/SSE 网络契约。没有声称测试了浏览器原生 HTTP 页面导航、原生 SSE 重连全部网络条件、公网部署、Safari 或 Firefox。页面历史 URL 回写在夹具中保存为测试值，不把它当成真实浏览器前进后退验证。

旧判断实验回归仅修改导航到新页签、展开高级项和版本标题断言，原行为、候选、请求、延迟和结果断言保留。旧共享观测台 DOM 已替换，其历史选择器脚本不当作本版通过记录；新版 63 项覆盖当前控制界面。可运行 `npm run test:browser` 自动开隔离本地服务并依次执行当前四套脚本。

确认了键盘页签、对话框焦点返回、手机 390px 无横向溢出和首屏地图；这不是形式化无障碍认证或穷尽安全审计。

## 已知未改变的问题

既有 Lab API 接受最高 3,600,000ms 的通用截止值，而 judgment 夹具内部检查上限是 120,000ms。该版本新建表单按实际实验类型限制输入并在字段无效时展开高级配置，但没有改变后端 API。CLI judgment 实验请设置不超过 120,000ms。此范围外的既有后端拒绝不是新 UI 的引擎修复。

底层仍保留先前边界：无真实模型效果证据、活动运行持久崩溃恢复、跨用户权限和货币硬预算。界面帮助理解证据，不替代正确性证明。
