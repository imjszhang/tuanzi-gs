# v0.2.1 — 执行证据、评价与有界纠错

本版在 v0.2 的确定性世界和线性计划范围内修复三项审查问题。它不加入反应式技能，也不声称消除了全部软件缺陷。

## 修复

1. `TrialEvidence` 从策略提交开始记录真实 transition，包括终止动作。核对计划索引、策略版本、前置状态、实际动作、执行回执和模拟后态。`goalSucceeded` 与 `exactReplay` 独立。偏离后任务可以成功，但不晋升原精确计划。取消、世界修改、中途恢复和无法确认的回执不能冒充成功样本。
2. `SkillBook` 保存有版本的结果向量和执行证据。少走几步不再自动淘汰另一计划。仅相同起点、同一目标版本、实测向量的 Pareto 支配可以淘汰；未提供结果向量的旧记录不参与自动淘汰。一次实测不是跨条件可靠性保证。本地记录未经认证，始终需要模拟复检，不能赋予权限。
3. 引擎新增 `maxProposalAttempts`（兼容默认 1，游戏设为 3）和 `Context.repairFeedback`。结构/模拟拒绝可以在根模型与修复预算内修正。每次尝试独立计数，取消、网络故障、过期世界不做隐藏重试。远端程序端点 opt-in `repairProtocol` 返回 422 结构化拒绝及实际提供商 usage，下一请求携带反馈。

## 验证

运行 `npm run build && npm test`。127 项代码测试，包括原 109 项和新增 18 项。新增本地 HTTP 模拟服务检验失败步骤、反馈转发、被拒调用的用量与服务器总预算；不使用真实模型。

运行 `python scripts/browser-v021.py` 检查实际单文件 HTML。测试进度与最终报告写入 reports。浏览器存储跨页面测试使用显式 Storage 夹具，不能作为 file:// 持久化保证。
