## 新覆盖的关键行为

- constructor、create、inspect、export和订阅不发起G/S请求。
- 首次实际顺序G→元层S→动作S；初始G拿到当时允许的世界，answer=null，无虚构S失败/历史。
- 新建后编辑、action0脚本干预发生在G观察前；G得到最新状态。
- G可增加/删减S可见组与候选范围，初始S即使候选唯一仍可none。
- 多次step、暂停恢复、命令重放不重复启动G；checkpoint分支即使继承自身记忆也重新研判。
- 初始化的坏结构有界纠错、网络失败、取消、根额度耗尽、元层拒绝均不产生默认S动作。
- G期间或首个S动作提交前世界改变，丢弃旧结果、保留预算，在新快照重新初始化。
- G可明确确认初始条件不必改动；后续仅改标题/重置阶段时钟仍不算新修订。
- 起点已成功、死亡或物理回合耗尽直接根验收，不发无意义请求。
- 所有初始调用计入正常账本；purpose=initialization，格式纠错保留originalCause。
- 元层S仍可递归，请求/深度/修订配额共享；初始化状态不代表策略正确。
- UI显示开局G、初始条件提交与失败，旧报告不伪造初始化；回放只显示当时记录。

## 回归迁移

既有部分测试用“首次S必须返回none”仅为了触发G。现在改为G直接启动，专门测试S弃权/错误恢复的用例则先完成明确的测试初始化，再注入原本的S错误；仍检查真实上下文/回答回传与同会话恢复。流式/格式夹具更新为从首次G进入，不再把元层S的第一次调用误当动作S。未跳过这些测试。

生产server.mjs + CLI + 本机模拟供应商回归仍验证格式修复、元层S和一次真实动作，新的请求次序少了原先用于触发G的那一次动作S请求。模型凭据均为测试用假值，导出不含授权头或测试密钥。

## 浏览器范围

本轮确实尝试Chromium原生本机HTTP导航，环境返回ERR_BLOCKED_BY_ADMINISTRATOR。因此浏览器使用发行HTML/JS/CSS字节，通过测试传输桥连接真实本地实验服务；原生HTTP/SSE网络通过Node集成测试覆盖。不是Safari/Firefox、跨设备或公网部署验证。

截图来自明确标识的MOCK启动夹具，物理世界使用守卫果园但回调不求解任务，只用于检查G未完成时的零动作与流式显示。未改地图视觉素材或新增网络图片。
